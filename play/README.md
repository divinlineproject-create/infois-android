## Urutan kerja pemilik di Play Console

1. Buat akun developer (US$25) atas nama **PT. DEVINE AUTADA TECH** (akun organisasi: butuh D-U-N-S).
2. Create app: nama "Infois POS: Kasir & Tim AI", bahasa default Indonesia, App (bukan game),
   Free, centang deklarasi.
3. Isi App content (`app-content.md`, `data-safety.md`, `account-deletion.md`).
4. Isi Main store listing (`listing-id.md`, `screenshots.md`).
5. Testing › Internal testing: unggah `app-release.aab`, aktifkan Play App Signing (`RELEASING.md`).
6. Setelah lolos: Production (negara: Indonesia).
